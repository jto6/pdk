Boot Mode Fuse Writer TISCI Description¶

Note

This document is only applicable to AM62L devices.

This chapter provides information on System Firmware API for Boot Mode Writer Service. The available APIs are listed below.

TISCI Message ID Message Name Available in HS-FS Available in HS-SE
0x9044 TISCI_MSG_SET_OTP_BOOT_MODE YES YES

API Description¶

TISCI_MSG_SET_OTP_BOOT_MODE - Program a boot mode efuse¶

Usage:

Message Type Normal
Secure Queue Only? No

TISCI Message ID¶

TISCI_MSG_SET_OTP_BOOT_MODE          (0x9044U)

Message to program boot mode

struct tisci_msg_set_otp_boot_mode_req

Request to set boot mode

Parameter Type Description
hdr struct tisci_header Common tisci header
boot_mode_efuse_idx u8 The boot mode efuse to program
resv u8 Reserved field of 3 bytes
write_val u32 Number containing the 25-bit value to be blown

struct tisci_msg_set_otp_boot_mode_resp

Response to set boot mode request

Parameter Type Description
hdr struct tisci_header Common tisci header

Note

For more information refer to boot mode writer user guide
