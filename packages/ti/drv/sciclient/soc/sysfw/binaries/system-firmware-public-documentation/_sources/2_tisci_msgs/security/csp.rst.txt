================================
Crypto Service TISCI Description
================================

.. _csp_tisci_desc:

This chapter provides information on  |sysfw| API for Cryptographic Services. The available API are listed below.

+-------------------+---------------------------------------------------+-----------------+--------------------+--------------------+-----------------------------+
|  TISCI Message ID |  Message Name                                     | Available in GP | Available in HS-FS | Available in HS-SE | Previous Message Name       |
+===================+===================================================+=================+====================+====================+=============================+
| 0x9040            | :ref:`TISCI_MSG_CRYPTO_AES_ENCRYPT <csp-encrypt>` | NO              | YES                | YES                | TISCI_MSG_SA2UL_AES_ENCRYPT |
+-------------------+---------------------------------------------------+-----------------+--------------------+--------------------+-----------------------------+
| 0x9041            | :ref:`TISCI_MSG_CRYPTO_AES_DECRYPT <csp-decrypt>` | NO              | YES                | YES                | TISCI_MSG_SA2UL_AES_DECRYPT |
+-------------------+---------------------------------------------------+-----------------+--------------------+--------------------+-----------------------------+

.. note::
  The TISCI Message ID macros have been renamed. Please update your code to use the new names.

API Description
===============

Request and Response structures
-------------------------------

.. code-block:: c

    struct csp_aes_opn_req_data {
        u32 ctx_address_lo;
        u32 ctx_address_hi;
    }

    struct csp_aes_opn_resp_data {
        u8 tag[16];
    }
