=============================
AM275X Processor Descriptions
=============================

.. _soc_doc_am275x_public_proc_desc_intro:


Introduction
============

This chapter provides information of Processor and Host IDs that are permitted
in the AM275X SoC. These Processor IDs represent an actual physical processor
on the SoC.

NOTE: This should not be confused with HOST_ID.

.. _soc_doc_am275x_public_proc_desc_processors_list:
